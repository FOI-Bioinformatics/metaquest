# Technical Debt Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pay down the debt the 2026-09-25 technical-debt report measured: broad exception handling, two output channels, three modules with a maintainability index below 10, an untyped registry, a dead and over-heavy dependency set, two overlapping SRA command families, and no real-data run in CI. Ship the breaking parts as 0.5.0.

**Architecture:** Non-breaking work first (exception narrowing, one output helper, audit in CI, docstrings, module splits, typed registry blocks, nightly smoke), then the breaking changes (lazy optional dependencies with extras, SRA command consolidation), then the release. Every task leaves `make check` and `make test` green and is independently mergeable. Import paths move freely; no compatibility shims (the user's choice), but renamed commands print a one-line pointer to the new name.

**Tech Stack:** Python 3.12, argparse command registry (`metaquest/cli/base.py`, `metaquest/cli/main.py`), dataclasses, pytest on tmp_path, flake8 with plugins, radon, GitHub Actions with conda for the smoke job.

**Spec:** the technical-debt report given in the session of 2026-09-25 (measurements: 118 `except Exception`, 67 functions at complexity 11-20, MI 0.0/3.7/8.8 for store.py/status.py/sra.py, 179 CLI prints plus 10 library prints, 243 of 582 public defs without docstring, 4 dead dependencies, 43 commands). Merged state: `main` at 85858f9 (v0.4.0).

## Global Constraints

- Python >= 3.12; line length 120; black, flake8 (max-complexity 15), mypy, radon rank ceiling D via `make check`; `make test` green per commit; ASCII only; plain scientific wording; CLI flags use dashes.
- Tests on tmp_path with the store env monkeypatched; no external tool on PATH except `sleep`; no network except in `tests/test_network_smoke.py` (marker `network`).
- Every behavioural change has a RED test first. Commit trailer: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Never `git add` AGENTS.md.
- All Python runs through the 3.12 conda env (`conda run -n metaquest ...` or an activated env); the 3.11 base interpreter is unsupported.
- Breaking changes (Tasks 8, 9) land only after Tasks 1-7 and are listed under "Breaking" in the 0.5.0 changelog (Task 12).
